# Jarvis AI

An autonomous Android AI assistant powered by:

- OpenAI / Gemini Vision
- OCR
- ADB automation
- Multi-step autonomous execution
- State tracking
- Vision-based decision making
- Recovery system
- Action memory

## Features

- Open apps
- Search YouTube
- Play music/videos
- Autonomous UI interaction
- OCR phrase matching
- Ad skipping
- Smart recovery system

## Tech Stack

- Python
- ADB
- OpenCV
- Tesseract OCR
- OpenRouter
- Gemini Vision
